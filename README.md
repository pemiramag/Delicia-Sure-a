# 🍲 Restaurante Delicia Sureña · Landing Page de Alta Conversión

Landing page moderna inspirada en la arquitectura visual y microinteracciones de **[Ember Kebab & Pizza House](https://ember-kebab-pizza-house.framer.website/)**, adaptada al 100% a la identidad de **Restaurante Delicia Sureña** (Catambuco, San Juan de Pasto, Nariño).

---

## 🚀 Entorno de Desarrollo Web Instalado

El entorno de desarrollo local ha sido configurado por completo con las siguientes herramientas instaladas y funcionales:

- **Node.js**: v20.18.3 (LTS)
- **npm**: v10.8.2
- **Git**: v2.44.0 (Windows 64-bit)
- **Stack Frontend**: React 18 + Vite 5 + Tailwind CSS + Lucide React
- **Servidor Local**: Activo en `http://localhost:3000/`

---

## 🛠️ Comandos Disponibles

En la raíz del proyecto (`c:\Users\ParqueSoft\Documents\Delicia Sureña`):

```bash

npm run dev

# Generar compilación optimizada para producción:
npm run build

# Previsualizar la compilación de producción:
```

## 📂 Estructura de Secciones Desarrolladas

1. **TopBar**: Notificación en vivo de apertura, calificación de 4.9 estrellas, ubicación en Catambuco.
2. **Navbar**: Barra pegajosa (glassmorphism), logotipo oficial, enlaces y botón de pedido instantáneo.
3. **Hero**: Titular de impacto, dual CTAs de alta conversión y 4 garantías del fogón tradicional.
4. **Signatures (Especialidades)**: Cuy Asado ($76.000 COP), Costillas Ahumadas, Sancocho de Gallina y Fritada con enlace directo por WhatsApp.
5. **MenuChapters (La Carta)**: Explorador por capítulos interactivos (01 Brasas, 02 Sopas, 03 Entradas, 04 Bebidas y Postres).
6. **CraftStory (El Fogón y la Historia)**: Filosofía del restaurante, rescate de la tradición culinaria nariñense y fotos del local.
7. **LocationCard (Catambuco)**: Horarios, datos de contacto y enlace a Google Maps.
8. **ReviewsSection (Testimonios)**: Prueba social de clientes locales y turistas.
9. **CateringSection (Eventos)**: Cotizador rápido de banquetes para celebraciones y grupos.
10. **FloatingWhatsApp**: Botón flotante permanente con mensaje personalizado según plato.
